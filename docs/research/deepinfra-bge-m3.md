# BGE-M3 напрямую через DeepInfra

Проверено 9 августа 2026 года по официальным страницам DeepInfra, BAAI и
Центрального банка России.

## Краткий вывод

`BAAI/bge-m3` можно подключить к Grounded Docs v3 напрямую через DeepInfra без
изменения кода. DeepInfra предоставляет стандартный OpenAI-совместимый endpoint,
а текущий Grounded уже умеет задавать произвольный `OPENAI_API_BASE` и модель.

Прямое подключение имеет смысл прежде всего ради меньшей цены и исключения
агрегатора. Ожидать улучшения качества самой модели оснований нет: Polza указывает
для BGE-M3 backend `deepinfra/fp32`, то есть сейчас, вероятнее всего, перепродаёт
тот же инференс DeepInfra.

Перед полной переиндексацией нужен короткий запрос с новым ключом DeepInfra:
проверить размерность и L2-норму ответа. Публичный запрос без ключа вернул `401
missing API key`, поэтому нормализация именно OpenAI-совместимого ответа DeepInfra
пока не подтверждена экспериментально.

## Параметры модели и API

| Параметр | Значение |
|---|---|
| Model ID | `BAAI/bge-m3` |
| Base URL для Grounded | `https://api.deepinfra.com/v1/openai` |
| Фактический endpoint | `POST https://api.deepinfra.com/v1/openai/embeddings` |
| Формат запроса | OpenAI embeddings: `model`, `input`, `encoding_format` |
| Формат ответа | `data[].embedding` как массив чисел и `usage` |
| Нативная размерность | 1024 |
| Контекст одного текста | до 8192 токенов |
| Размер batch в API | до 1024 элементов |
| Цена default tier | **$0,01 за 1 млн входных токенов** |

Официальная [страница API модели](https://deepinfra.com/BAAI/bge-m3/api)
показывает запрос к `/v1/openai/embeddings`, ответ OpenAI-формата и использование
официальных OpenAI-клиентов с `base_url=https://api.deepinfra.com/v1/openai`.
Публичная [метаинформация модели](https://api.deepinfra.com/models/BAAI/bge-m3)
подтверждает цену, контекст 8192, batch до 1024 и вариант `fp32`. Нативная
размерность 1024 подтверждается `hidden_size` в официальном
[config.json BAAI](https://huggingface.co/BAAI/bge-m3/blob/main/config.json).

Штатная конфигурация Grounded:

```env
OPENAI_API_BASE=https://api.deepinfra.com/v1/openai
OPENAI_API_KEY=...
DOCS_MCP_EMBEDDING_MODEL=openai:BAAI/bge-m3
DOCS_MCP_EMBEDDINGS_VECTOR_DIMENSION=1024
```

Ключ должен храниться только в локальном secret storage. Смена endpoint или
идентичности embedding-модели требует повторной индексации всех векторов.

## Instructions и `input_type`

Специальная инструкция для поискового запроса не нужна. Официальная карточка
BGE-M3 прямо говорит, что BGE-M3, в отличие от прежних BGE, больше не требует
добавлять instructions к queries. Поэтому одинаковая обработка документов и
запросов в Grounded подходит этой модели.

Общая схема DeepInfra принимает необязательный `input_type` для асимметричных
моделей и отмечает, что он игнорируется симметричными моделями. Grounded его не
передаёт, и для BGE-M3 это не является ограничением.

Источники: [официальная карточка BGE-M3 в DeepInfra](https://deepinfra.com/BAAI/bge-m3),
[официальный README BGE-M3](https://huggingface.co/BAAI/bge-m3),
[схема OpenAI Embeddings DeepInfra](https://docs.deepinfra.com/api-reference/embeddings/openai-embeddings).

## Batch и rate limits

DeepInfra допускает до 1024 текстов в одном embeddings-запросе. Grounded уже
делит документы на batch по 512, поэтому лимит соблюдается без изменения кода.
LangChain-клиент Grounded по умолчанию выполняет не более двух таких запросов
одновременно.

Для аккаунта DeepInfra официальный лимит по умолчанию — 200 одновременно
выполняющихся запросов на одну модель. Это не RPM-лимит; освободившийся слот можно
использовать сразу. При перегрузке возможен `429`, после которого DeepInfra
рекомендует повторить запрос с задержкой. Текущая параллельность Grounded намного
ниже лимита.

Источник: [DeepInfra Rate Limits](https://docs.deepinfra.com/account/rate-limits).

## Цена относительно Polza

DeepInfra указывает **$0,01 за 1 млн входных токенов**. Polza на публичной
[странице BGE-M3](https://polza.ai/models/baai/bge-m3) показывает округлённо
около **1,13 рубля за 1 млн токенов**; точное значение из текущего каталога
Polza — 1,125252 рубля.

Официальный курс ЦБ РФ на 8 августа 2026 года — 82,1665 рубля за доллар. При
этом курсе цена DeepInfra составляет приблизительно:

- **0,821665 рубля за 1 млн токенов**;
- на **0,303587 рубля**, или примерно **27%**, дешевле Polza;
- для оценочного корпуса 6,1 млн токенов: около **5,01 рубля** через DeepInfra
  против **6,86 рубля** через Polza, экономия около **1,85 рубля** на полной
  индексации.

Точка равенства цен — курс примерно 112,53 рубля за доллар. Ниже этого курса
DeepInfra дешевле по чистому API-тарифу. Реальная сумма списания может отличаться
из-за курса банка, комиссии и налогов. DeepInfra выставляет расходы в USD и
использует Stripe Checkout для пополнения.

Источники: [страница модели DeepInfra](https://deepinfra.com/BAAI/bge-m3),
[курс ЦБ РФ](https://www.cbr.ru/scripts/XML_daily.asp?date_req=09/08/2026),
[DeepInfra Add Funds](https://docs.deepinfra.com/api-reference/billing/add-funds).

## Плюсы и минусы прямого подключения

Плюсы:

- примерно на 27% дешевле при текущем официальном курсе;
- прямой доступ к фактическому backend без промежуточного агрегатора;
- штатный OpenAI-совместимый интерфейс, код Grounded менять не нужно;
- запас по batch и concurrency намного выше текущей нагрузки Grounded;
- в API DeepInfra виден расход токенов и есть отдельные методы учёта billing.

Минусы:

- экономия в абсолютных рублях на нынешнем небольшом корпусе почти незаметна;
- отдельный аккаунт, USD-биллинг и новый секрет DeepInfra;
- цена в рублях зависит от курса и условий платежа;
- смена endpoint потребует полной переиндексации, даже если модель та же;
- OpenAI endpoint не документирует параметр `normalize`, а нативная схема
  DeepInfra имеет `normalize=false` по умолчанию. До миграции нужно проверить
  L2-норму реального ответа и сравнить несколько cosine similarity с Polza.

## Рекомендация

Перейти на DeepInfra можно без доработки Grounded, но делать это ради качества
не стоит: модель и fp32-backend у Polza заявлены те же. Рациональный порядок:

1. Вернуть рабочий сервер на полный backup BGE-M3 через Polza.
2. Завести отдельный ключ DeepInfra, не меняя рабочую конфигурацию.
3. Одним дешёвым запросом проверить HTTP 200, размерность 1024 и L2-норму.
4. На одинаковых русских строках сравнить матрицу cosine similarity Polza и
   DeepInfra.
5. Только при паритете переключить endpoint и запустить полную индексацию.

Так переход даст небольшую экономию и прямой договор с провайдером без риска
незаметно изменить ранжирование.

## Живой probe с рабочим ключом

9 августа 2026 года API проверен рабочим ключом DeepInfra без переключения
production-сервера.

- `BAAI/bge-m3-multi` для одного русского текста через OpenAI endpoint ответил
  за 0,887 секунды, вернул float-массив 1024d с L2-нормой `1,000247344`.
- Cosine между этим вектором и ответом Polza `baai/bge-m3` для той же строки —
  `0,999999024`. Практически это один dense embedding.
- `BAAI/bge-m3` с `service_tier=priority` в одном запуске ответил за 0,814
  секунды и дал норму `0,999999981`, но повторные одиночные запросы были
  нестабильны и доходили до timeout.
- Массивы из двух-трёх коротких строк зависали на 45–120 секунд и завершались
  `TimeoutError`. Это повторилось для `bge-m3` и `bge-m3-multi`, standard и
  priority, OpenAI-compatible и native inference endpoints.
- Priority стоит 1,5 базового тарифа: для BGE-M3 это `$0,015 / 1M`, то есть при
  проверенном курсе уже дороже текущего тарифа Polza.

Текущий Grounded отправляет документы batch-ами до 512 элементов. Поэтому на
момент проверки прямой DeepInfra нельзя использовать как production drop-in:
одиночный vector query работает, но полная индексация будет зависать. Для
повторной оценки нужен либо подтверждённый ответ DeepInfra об исправлении batch,
либо адаптер с `batchSize=1`, retry/backoff и явным контролем service tier.
