# Самые дешёвые managed reranker API для русскоязычного RAG

Дата проверки: 2026-08-09.

## Короткий вывод

- **Минимальная постоянная цена:** DeepInfra `Qwen/Qwen3-Reranker-0.6B` — **$0.010 за 1 млн токенов**. При фактическом объёме текущего теста это примерно **$0.000477 за запрос** и **$0.0191 за 40 запросов**.
- **Минимальные фактические расходы для нового аккаунта:** Voyage `rerank-2.5-lite` — **$0 до исчерпания 200 млн бесплатных rerank-токенов**; затем $0.020 за 1 млн токенов. Текущий тест из 40 запросов использует 1.906 млн токенов, поэтому полностью укладывается в бесплатный объём.
- Voyage Lite проверен на полном 40-вопросном наборе и оказался лучше Qwen 8B:
  `MRR 0.933`, `nDCG@5 0.937`, `Hit@1 0.900`, средняя задержка 1.11 с.
- DeepInfra Qwen 0.6B уже проверен тем же 40-вопросным тестом: `MRR 0.868`,
  `nDCG@5 0.884`, `Recall@3 0.938`, `Hit@1 0.775`. Он заметно улучшает
  исходный поиск, но уступает Qwen 8B.
- Итоговый выбор для первого релиза — **Voyage rerank-2.5-lite**; Qwen 0.6B
  остаётся самым дешёвым постоянным fallback после free tier.

## База расчёта

По завершённому тесту Qwen3-Reranker-8B:

- средний вход одного запроса: **47 654 токена**;
- 40 запросов: **1 906 170 токенов**.

Для токенных тарифов расчёт: `токены / 1 000 000 × цена`. Для Cohere токены не используются: один запрос с максимум 100 документами считается одной search unit.

### Важное различие подсчёта токенов

Voyage определяет rerank-токены как `(query tokens × document count) + сумма document tokens`. Это соответствует обычному cross-encoder подсчёту пар query/document. В API разрешено до 1 000 документов и до 600K total tokens на запрос для `rerank-2.5-lite`.

Живая проверка нового аккаунта показала дополнительное ограничение: до
добавления платёжного метода Voyage применяет `3 RPM` и `10K TPM`. Короткие
запросы на 1–3 документа проходят, но текущий внешний запрос top-30 примерно на
47 тысяч токенов получает HTTP 429. Платёжный метод нужен для разблокировки
штатных лимитов даже при использовании бесплатных 200 млн токенов.

Cohere тарифицирует search units: одна unit — один query с максимум 100 документами. Поэтому 47 654 токена в нашем запросе не меняют цену, пока Grounded отправляет не более 100 кандидатов и не разбивает запрос.

| SiliconFlow | Официальный `/v1/rerank` перечисляет Qwen3-Reranker 0.6B, 4B и 8B | На доступной официальной pricing-странице не удалось однозначно связать текущую цену с этими моделями; не ранжируем без подтверждённого тарифа |
| Jina AI | Есть multilingual reranker API/model family | Текущая официальная pricing-страница из проверяемой сети отвечает HTTP 451; актуальную цену и free tier нельзя подтвердить первичным источником, поэтому Jina не участвует в рейтинге |

| Polza.ai | В проверенном публичном каталоге не подтверждён отдельный rerank API для Qwen/BGE reranker | Embeddings endpoint нельзя считать rerank API; модели не включены в расчёт |
| NVIDIA-hosted / NIM | Есть модели reranking и бесплатный прототипный доступ к API Catalog | Публичного production PAYG тарифа, сопоставимого с ценой за токены/поиск, не подтверждено; self-hosted/dedicated GPU — другая модель оплаты |
| OpenRouter | Chat/completions routing не равен rerank endpoint | Не учитывать как reranker без специального API |

## Практическая рекомендация

1. **Выбрать Voyage `rerank-2.5-lite` для первого релиза**: на текущем объёме он бесплатен, имеет официальный multilingual support, обычный rerank endpoint и показал лучшее качество в нашем тесте.
2. **DeepInfra Qwen3-Reranker-0.6B уже протестирован.** После бесплатного периода это самый дешёвый подтверждённый постоянный тариф: примерно **$0.019 за 40 запросов** или **$0.48 за 1 000 запросов** текущего, пока ещё неоптимизированного размера.
3. Qwen 0.6B оставить как самый дешёвый постоянный запасной вариант после
   исчерпания Voyage free tier.
4. После переноса reranker внутрь Grounded **до расширения контекста** токенов на запрос станет существенно меньше, поэтому обе модели подешевеют пропорционально.

## Живой тест самого дешёвого постоянного варианта

`Qwen/Qwen3-Reranker-0.6B` проверен с удалённого сервера на том же наборе из 40
вопросов и тех же top-30 кандидатах.

| Метрика | Без reranker | Qwen 0.6B | Qwen 8B |
|---|---:|---:|---:|
| MRR | 0.684 | 0.868 | 0.917 |
| nDCG@5 | 0.712 | 0.884 | 0.923 |
| Recall@3 | 0.688 | 0.938 | 0.975 |
| Hit@1 | 0.575 | 0.775 | 0.875 |

- 0.6B: 15 улучшений, 5 ухудшений, 20 без изменений.
- Средняя задержка 0.6B: 1.91 секунды против 4.58 секунды у 8B.
- P95 0.6B: 2.88 секунды.
- Стоимость 40 вопросов: `$0.01906` против `$0.09531` у 8B.

Таким образом, Qwen 0.6B — уже подтверждённый рабочий минимум постоянной цены,
а не только дешёвая модель из каталога.

## Живой тест Voyage rerank-2.5-lite

После добавления платёжного метода штатные лимиты Voyage были разблокированы.
Платёжный метод нужен для снятия стартовых `3 RPM / 10K TPM`, но тест остался в
пределах бесплатных 200 млн токенов.

| Метрика | Без reranker | Qwen 0.6B | Qwen 8B | Voyage Lite |
|---|---:|---:|---:|---:|
| MRR | 0.684 | 0.868 | 0.917 | **0.933** |
| nDCG@5 | 0.712 | 0.884 | 0.923 | **0.937** |
| Recall@3 | 0.688 | 0.938 | **0.975** | **0.975** |
| Hit@1 | 0.575 | 0.775 | 0.875 | **0.900** |
| Средняя задержка | — | 1.91 с | 4.58 с | **1.11 с** |

- Voyage: 17 улучшений, 2 ухудшения, 21 результат без изменений.
- P95: 1.26 секунды.
- Использовано 1 816 288 rerank-токенов.
- Текущая стоимость: `$0` благодаря free tier.
- После free tier тот же тест стоил бы около `$0.0363`.

Voyage Lite — лучший проверенный вариант одновременно по фактической стоимости,
качеству и задержке.
