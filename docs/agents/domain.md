# Domain Docs

This repository uses a single domain context.

Before exploring or changing the codebase, read the root `CONTEXT.md` and the
relevant accepted decisions under `docs/adr/`. Use the canonical terms from the
glossary in issues, plans, tests, and implementation discussions. The glossary's
`_Avoid_` entries identify noncanonical language.

If a proposed change conflicts with an ADR, state the conflict explicitly. If a
required domain term is missing, use the domain-modeling workflow to define it
canonically.
