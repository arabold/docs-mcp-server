# Issue tracker: GitHub

Issues and specs for this fork live in GitHub Issues at
`AlekseiSeleznev/docs-mcp-server`. Use the `gh` CLI for issue operations.

## Conventions

- Create, read, update, label, and close work through `gh issue` commands.
- Infer the repository from the `origin` remote when running inside this clone.
- A request to publish to the issue tracker means creating a GitHub issue.
- GitHub Issues are the exclusive request and triage surface for this
  repository.
- Resolve a bare issue or pull request number before acting because GitHub uses
  one number sequence for both.
